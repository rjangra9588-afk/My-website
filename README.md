## 📝 Customization Guide

### Update Company Information
Edit the following sections in `index.html`:

```html
<!-- Contact Information -->
<p>+1 (555) 123-4567</p>  <!-- Change phone number -->
<p>info@rahamarketing.com</p>  <!-- Change email -->
<p>Your City, Country</p>  <!-- Change location -->
```

### Change Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;      /* Indigo */
    --secondary-color: #ec4899;    /* Pink */
    --dark-color: #1f2937;         /* Dark Gray */
}
```

### Add Portfolio Items
Add new items to the portfolio grid:
```html
<div class="portfolio-item">
    <div class="portfolio-image">
        <i class="fas fa-star"></i>
    </div>
    <h4>Project Title</h4>
    <p>Project description</p>
</div>
```

### Update Service Descriptions
Edit the service cards in the Services section with your specific offerings and features.
