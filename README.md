# RAHA Marketing Media - Professional Website

A modern, responsive website for RAHA Marketing Media, a full-service digital marketing and creative agency.

## 🎨 Features

### Services Offered
- **Social Media Marketing (SMM)** - Content strategy, account management, community engagement, paid campaigns
- **Social Media Optimization (SMO)** - Profile optimization, SEO for social media, algorithm mastery
- **Video Production** - Scriptwriting, professional filming, studio shoots, post-production
- **Video Editing** - Color grading, motion graphics, sound design, special effects
- **Graphic Design** - Logo design, brand identity, social media graphics, print materials
- **Complete Package** - All services bundled together for maximum impact

### Website Components
✅ **Responsive Navigation** - Mobile-friendly hamburger menu
✅ **Hero Section** - Eye-catching landing area with CTA
✅ **Services Section** - Detailed service offerings with features
✅ **Portfolio** - Showcase of completed projects
✅ **About Section** - Company information with statistics
✅ **Contact Section** - Contact form and business information
✅ **Social Media Links** - Links to all major platforms
✅ **Mobile Optimized** - Works perfectly on all devices

### Design Highlights
- Modern gradient color scheme (Indigo & Pink)
- Smooth animations and transitions
- Professional typography
- Hover effects on interactive elements
- Fully responsive grid layouts
- Font Awesome icons integration

## 🚀 Getting Started

### Requirements
- Modern web browser
- No dependencies or build tools needed
- Works offline after initial load

### Files Included
- `index.html` - Main HTML structure
- `styles.css` - Complete styling with responsive design
- `script.js` - Interactive features and animations
- `README.md` - This file

### How to Use

1. **Clone or Download** the repository
2. **Open `index.html`** in your web browser
3. **Customize** the content with your specific information:
   - Update phone number, email, and address in the contact section
   - Replace placeholder portfolio items with real work
   - Update statistics in the About section
   - Add your company details
